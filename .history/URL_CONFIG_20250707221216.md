# Cấu hình URL cho Development và Production

## 🎯 Tóm tắt

Hệ thống đã được cấu hình để tự động sử dụng đúng URL cho mỗi môi trường:

| Môi trường | URL | Mock VNPay URL |
|------------|-----|----------------|
| **Development** | `http://localhost:3000` | `http://localhost:3000/vnpay/checkout` |
| **Production** | `https://gearhub-vn.vercel.app` | `https://gearhub-vn.vercel.app/vnpay/checkout` |

## ⚙️ Cách hoạt động

### 1. Thứ tự ưu tiên để xác định Base URL:

1. **NEXT_PUBLIC_BASE_URL** (từ .env hoặc vercel.json)
2. **VERCEL_URL** (Vercel tự động set)
3. **Request Headers** (host + protocol)
4. **Hardcode Fallback** (dựa trên NODE_ENV)

### 2. Cấu hình hiện tại:

#### Development (.env):
```bash
NEXT_PUBLIC_BASE_URL=http://localhost:3000
```

#### Production (vercel.json):
```json
{
  "env": {
    "NEXT_PUBLIC_BASE_URL": "https://gearhub-vn.vercel.app"
  }
}
```

Để kiểm tra URL được sử dụng, xem console logs khi thanh toán:


## 🚀 Test

### Development:
1. `npm run dev`
2. Checkout → VNPay → URL sẽ là `localhost:3000/vnpay/checkout`

### Production:
1. Deploy lên Vercel
2. Checkout → VNPay → URL sẽ là `gearhub-vn.vercel.app/vnpay/checkout`

## 🔧 Tùy chỉnh

Để thay đổi URL production, cập nhật trong `vercel.json`:

```json
{
  "env": {
    "NEXT_PUBLIC_BASE_URL": "https://your-new-domain.com"
  }
}
```

Sau đó redeploy.
