# Hướng dẫn cấu hình Email SMTP

## Gmail SMTP Setup

### 1. Tạo App Password cho Gmail

1. **Đăng nhập vào Gmail** của bạn
2. **Vào Google Account Settings**: https://myaccount.google.com/
3. **Chọn "Security"** (Bảo mật)
4. **Bật "2-Step Verification"** (Xác minh 2 bước) nếu chưa bật
5. **Tìm "App passwords"** (Mật khẩu ứng dụng)
6. **Chọn "Mail"** và **"Other (Custom name)"**
7. **Nhập tên**: "Gear Shop Email Service"
8. **Nhấn "Generate"** và **copy password** được tạo ra

### 2. Cập nhật file .env.local

```bash
# SMTP Email Configuration
SMTP_HOST=smtp.gmail.com
SMTP_PORT=587
SMTP_USER=your-email@gmail.com
SMTP_PASS=your-16-character-app-password
```

### 3. Thay thế thông tin thực

- `SMTP_USER`: Email Gmail của bạn (ví dụ: gearhubno1@gmail.com)
- `SMTP_PASS`: App Password vừa tạo (16 ký tự không có khoảng trắng)

### 4. Restart server

```bash
npm run dev
```

## Alternative SMTP Services

### SendGrid (Recommended for production)
```bash
SMTP_HOST=smtp.sendgrid.net
SMTP_PORT=587
SMTP_USER=apikey
SMTP_PASS=your-sendgrid-api-key
```

### Mailtrap (For testing)
```bash
SMTP_HOST=smtp.mailtrap.io
SMTP_PORT=2525
SMTP_USER=your-mailtrap-username
SMTP_PASS=your-mailtrap-password
```

## Troubleshooting

### Lỗi 534-5.7.9 "Please log in with your web browser"
- Đảm bảo đã bật 2-Step Verification
- Sử dụng App Password thay vì mật khẩu thường
- Kiểm tra App Password đã copy đúng (không có khoảng trắng)

### Lỗi 535 "Authentication failed"
- Kiểm tra email và password có đúng không
- Đảm bảo "Less secure app access" đã bật (không khuyến khích)
- Thử tạo lại App Password

### Test Email Connection
Truy cập: http://localhost:3000/api/debug/test-email để test kết nối SMTP
